# youtube-shorts

قناة شورتس علمية بالعربي، تشتغل تلقائياً:
- `engine/`: محرك الإنتاج. الانميشن يُرسم بـ canvas، والصوت من edge-tts، والمونتاج بـ ffmpeg.
- `episodes/`: لكل فيديو مجلد فيه السكربت والانميشن والفيديو النهائي.
- `topics.md`: قائمة المواضيع.
- `log.md`: سجل النشر وأرقام القناة.
- `CLAUDE.md`: خطوات العمل اليومية اللي تنفذها المهمة المجدولة.

النشر عبر Metricool في الساعة 16:00 بتوقيت الرياض.

مهارات `.claude/skills/yt-*` منسوخة من [youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill) (رخصة MIT).
